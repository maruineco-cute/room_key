# Room Key Atelier — 3D Room Key Maker

昔ながらのホテルルームキー型キーホルダーを、端末内だけでデザインできる静的 Web アプリです。ビルド工程・サーバー・ログインは不要で、GitHub Pages にそのまま配置できます。

## ファイル構成

```text
├── index.html   # UI
├── style.css    # レスポンシブ UI
└── app.js       # Three.js モデル、印刷用Canvas、操作処理
```

## 起動方法

ローカルでは、プロジェクト直下で静的サーバーを起動してください。

```bash
python3 -m http.server 8080
```

次に `http://localhost:8080` を開きます。Three.js は ESM CDN から読み込まれますので、`file://` で直接開くのではなく静的サーバー経由で確認してください。

## GitHub Pages での公開

1. この 3 ファイルをリポジトリのルートにコミットします。
2. GitHub の **Settings → Pages** を開きます。
3. **Deploy from a branch** を選択し、対象ブランチの `/ (root)` を指定します。
4. Save 後に発行される URL を開きます。

## 実装済みの操作

- 「モーテル型（添付イメージ風）」と「ラウンド型」を切り替えられる、押し出し 3D 形状
- 実際に抜かれたキーリング穴、メタルのアイレット、キーリング
- 表面・裏面それぞれに独立して PNG/JPEG/WebP/GIF（静止フレーム）を貼り付け
- 画像の透明部分を維持、サイズ・上下・左右を調整
- 表面・裏面別のテキスト、文字色、サイズ、上下・左右を調整
- 白系、黒、ピンク、水色、カスタム色のプラスチック本体
- ドラッグ/スワイプで 3D 回転、ホイールでズーム
- モバイルプレビュー右端に、3D 操作に捕まらずページをスクロールできる専用の余白レーン
- キー本体へのクリック/タップで、リングの穴を支点にした減衰振り子アニメーション
- ドラッグとタップを移動量で区別しているため、回転時に揺れは発火しません

## プライバシー

アップロードされた画像は `FileReader` と `Canvas` を使ってブラウザ内だけで扱います。画像データの送信・保存 API はありません。
